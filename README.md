# Playlist Maker

Учебное Android-приложение для поиска треков, создания плейлистов и управления избранным.  
Пользователь может искать музыку, сохранять понравившиеся треки в избранное, объединять их в плейлисты и просматривать детальную информацию.

## Основные возможности

- **Поиск треков** – ввод запроса, отображение результатов с обложкой, названием, исполнителем и длительностью в формате `mm:ss`.  
- **Избранное** – отдельный экран со списком любимых треков. Добавление и удаление (в том числе долгим нажатием).  
- **Плейлисты** – создание, редактирование и просмотр плейлистов с отображением количества треков. Добавление обложки (опционально).  
- **Детали трека** – экран с названием, исполнителем, временем и обложкой. Кнопки добавления в избранное и в плейлист.  
- **Настройки** – возможность поделиться приложением, написать разработчику или открыть пользовательское соглашение.  
- **Навигация** – плавные переходы между экранами через централизованный хост.

## Технические детали

- **Архитектура**: MVVM с разделением на Data / Domain / UI  
- **UI**: Jetpack Compose (LazyColumn, BottomSheet, навигация)  
- **Хранение данных**: Room (избранное, плейлисты), DataStore (история поиска)  
- **Сеть**: эмуляция через локальный репозиторий (моки)  
- **Язык**: Kotlin  

## Версии

- **Android Studio**: Giraffe 2022.3.1 (или актуальная на момент разработки)  
- **Kotlin**: 1.9.22  
- **minSdk**: 24 (Android 7.0)  
- **targetSdk / compileSdk**: 34 (Android 14)  

## Сборка и запуск

1. Клонируйте репозиторий:  
   `git clone https://github.com/ваш-логин/playlist-maker.git`
2. Откройте проект в Android Studio (версия не ниже указанной).
3. Дождитесь завершения Gradle Sync.
4. Запустите на эмуляторе или устройстве с API ≥ 24.
5. Дополнительных API-ключей не требуется.
